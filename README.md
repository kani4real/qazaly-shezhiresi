# Форт №1-ден Қазалы қаласына дейін

Қазалы қаласының құрылу шежіресі (1847–1906): интерактивті хронология, Сырдария шебі бекіністерінің картасы, дереккөздердегі «Дата дауы» және Python коды.

«Менің шағын Отаным» республикалық интеллектуалдық конкурсы, «Өлкемнің цифрлық шежіресі» номинациясы.

Сайт: https://kani4real.github.io/qazaly-shezhiresi/
